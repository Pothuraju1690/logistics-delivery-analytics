# Logistics Delivery Performance & Cost Analytics

## Project Description
Business analytics project for logistics delivery operations.

## Technology Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Run Pipeline

python run_pipeline.py

## Run Dashboard

streamlit run app/streamlit_app.py

## KPIs
- Total Orders
- Total Delivered
- On-Time %
- Average Delivery Days
- Total Logistics Cost
